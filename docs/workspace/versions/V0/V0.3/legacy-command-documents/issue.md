# Diagnose, fix and verify an issue

Read the active project and report. Record immediately with `python3 moom.py issue TITLE --scope project|helper|workflow|moom`, then fill the issue file with observed behavior, cause, affected version, correction and verification. Related reports can share one unreleased patch; do not manufacture a new project.

Fix the actual result under the user's existing authorization. Verify the real failure path; for interface bugs preserve native control behavior and test focus changes, not only a page with no focused control. Decide whether the job procedure, shared helper or general Moom instructions also need a correction. Record a narrow reusable lesson rather than a universal rule for one visual preference.

Update the project's patch version and package/deploy through the selected job's actual helpers when authorized. Record the deployed result and remaining limitations. Do not close the issue just because documentation was written.
