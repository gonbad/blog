# Import someone else's reusable method

Import into an empty destination with `python3 PATH/TO/moom.py --workspace DESTINATION import-job ARCHIVE`. The helper checks extraction paths and marks review required. Read the task contract, dependencies, examples and known limitations; confirm the recipient's environment and languages.

Create a small new instance using the imported procedure, then review the resulting decisions/artifact. Previous approval is historical evidence only. Do not import another person's projects, private memory or account sessions as shared defaults.
