# Current publication method

The installed [blog-publisher Job](job/blog-publisher/SKILL.md) is the current method
for every Project. Moom's [guide](docs/moom/guide.md) and [review protocol](docs/moom/review.md)
explain version ownership and review records. Legacy V8 procedures remain archived
under docs/job/versions/legacy-v8/ and are not executable instructions for this workspace.

The production steps are brief, story, content, layout, build, check, package and deploy.
Resolve one with `python3 moom.py procedure STEP`. Host adapters use
`job-blog-publisher-STEP`. Existing user instructions and authorization carry forward.
See the Job's distribution reference when declaring a new post, public source, downloads
or a workspace hosting adapter. Independent layouts remain independent.
