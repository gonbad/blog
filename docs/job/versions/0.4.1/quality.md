# Publishing quality criteria

- The visitor can identify the subject, audience, useful result and confirmed event facts.
- New claims are sourced; unconfirmed prices, hours, venue and registration availability are not invented.
- Every meaningful control performs its stated function. Navigation continues after interactions; editors and genuine widget controls retain their native keys.
- The presentation reads at phone and desktop sizes, with keyboard and reduced-motion routes checked.
- The actual offline ZIP opens through file:// with networking disabled, including local fonts and useful downloadable materials.
- The presentation ZIP never contains itself. A distinct downloadable Moom ZIP is legitimate material and may be included offline.
- Root links are literal and verified; project metadata does not generate index content.
- Public bytes match the selected build; unrelated server routes and registration health remain intact.
- Feedback can improve this project, a helper, this recipe or Moom; no timing benchmark is required.
