# Job — publish one useful instructional post

Produce a self-contained Persian site for a real tutorial, workshop introduction or handbook. Each post is an actual project with its own inputs/source and can receive issues and new versions. The root index is a separate editable project.

Start from the real instance, make a useful sample and refine the method through observed corrections. Current delivery is a manually navigated presentation and its offline ZIP. Audio/video are future selected features. A post can use another stack if its actual requirements justify it.

Authoritative source lives in projects/ID/. Review documents/state live in docs/projects/ID/. The workflow and actual stage procedures live here; host commands dispatch to the selected project's revision. Build/deploy helpers are bundled with frozen workflow revisions.

Known integration boundary: participant materials come from workshops/public-workflow/ and are packaged into the selected workshop post before publication. A general tutorial without workshop materials does not inherit this dependency.
