# Check source-to-result fidelity before visual completion

Read the selected version's primary 01-*.md input and source-to-result contract. Inspect the actual copy/controls against it: the first scene's problem, solution vs implementation, ordered reader actions, tasks delegated to the local AI, per-artifact language, required inputs, and explicitly removed scenes. Trace each material requirement to its rendered scene, control or generated artifact; record the result in fidelity.md in the selected version docs.

Do not approve a substituted story because it looks good or because its controls pass tests. Later direct owner instructions supersede inherited briefs/review packets. Routine necessary technical corrections should preserve the intended reader experience and be recorded concretely. New material choices requiring the owner follow the numbered file-review convention; submitted blanks delegate soft defaults under the workspace policy.

Functional browser/security/offline checks remain a separate stage. Claims that an output matches the source, that controls work, that an owner accepted it and that external provisioning worked are distinct.
