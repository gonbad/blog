# Journal vault

Open this `docs/` directory in Obsidian. Every file you open, read or edit is a `.md`
file inside `docs/` (including gitignored `secrets/credentials.md` files when needed).
Start with [Kandoo status](kandoo/living/status.md), [Job](kandoo/living/job.md),
[profile](kandoo/living/profile.md) and [Constitution](constitution/00-kandoo-principles.md).
Project living/version dossiers belong under [projects/](projects/README.md); actual
code and outputs live outside the vault and are operated by the assistant.

Old job/ and workspace/ version dossiers are preserved archives, including deployment
receipts. Feedback is write-only and has no runtime influence.

[Workspace maintenance: names, sources, Git, domains and publication removal](kandoo/maintenance.md).
