# Project dossiers

Each Project owns document root `docs/projects/ID/` (`living/` current facts including
`living/idea.md` and `living/status.md`, selected version dossier `versions/VERSION/`,
and gitignored `secrets/credentials.md` when needed) plus artifact root `projects/ID/`
outside this vault for code, public source and compiled outputs. The active selection is
in [shared status](../kandoo/living/status.md); switching restores the target's own
state without rebuilding old outputs. Existing imported version paths remain intact.
New Projects start at `0.1` with the current installed seven-stage Job.

The initial idea input links the selected dossier's `sources/notes.md` and
`living/sources.md` inventory. Reuse source files already supplied. A provisional
slug is explained at creation and resolved during idea review without changing the
numeric identity. All numbered records share one sequence across that dossier.
