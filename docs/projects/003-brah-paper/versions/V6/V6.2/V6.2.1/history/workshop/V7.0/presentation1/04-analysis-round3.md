> تاریخ: ۲۸ سپتامبر ۲۰۲۶
> مبنا: transcription + تحلیل‌های ۰۲ و ۰۳ + جواب‌ها + **نظرهای جدید کارفرما**
> روش پژوهش این دور: `webfetch` + `curl` مستقیم از همین ماشین (جست‌وجوی داخلی `websearch` همچنان `cancelled` می‌دهد — توضیح در بخش ۰). هر ادعایی که نتوانستم مستقیم بخوانم، با برچسب وضعیت مشخص کرده‌ام، نه به‌عنوان واقعیت.

## ۰. پاسخ به تذکرها

### ۰.۱ اشتباه FreeBuf — حق با شماست، عذرخواهی و اصلاح
من اشتباه کردم: `freebuf.com` (رسانه امنیت چین) را با **`https://freebuff.com`** (با دو f) قاطی کردم. سایت freebuff.com را مستقیم خواندم و واقعی است:
- **FreeBuff = ایجنت کدنویسی ۱۰۰٪ رایگان** (جایگزین Claude Code و Codex و Cursor و Lovable)، با مدل درآمدی تبلیغات.
- پنج محصول: **Desktop، CLI، Web، Cloud، Chat**. ادعای خودش: ۵۱۷ هزار توسعه‌دهنده.
- مدل مصرف: **Freebucks روزانه** (هر روز ۱۰۰ واحد، بدون اشتراک)؛ مثلاً روزانه ۲۰ ساعت GLM 5.3 Flash، ۱۰ ساعت MiMo 2.6 Flash، ۶ ساعت DeepSeek V4.1 Flash، ۶ ساعت Muse Spark 1.2، ۵ ساعت GPT-6 Luna، ۳ ساعت MiMo 2.6 Pro. (اعداد از صفحه اصلی خودشان است، در اسلاید تاریخ بزن.)
- جدول مقایسه قیمتی خودشان: OpenCode ‎$120/yr، Codex ‎$240، Cursor ‎$720، Claude Code ‎$1,200، Devin ‎$2,400، FreeBuff ‎$0.
- در تحلیل دور دوم گفتم «ابزار نیست» — **آن جمله پس گرفته شد.** FreeBuff در کاتالوگ این دور یک ردیف کامل دارد و چون رایگان است، برای مخاطب دانشجو مهم‌ترین گزینه آزمایش است.

### ۰.۲ چرا websearch کار نمی‌کند؟ آیا Devin را صدا بزنم؟
- ابزار `websearch` این محیط روی هر کوئری خطای `cancelled` می‌دهد (۵ بار تست شد). مشکل از من یا شما نیست، از اتصال خود ابزار است.
- ولی **اینترنت دارم**: همین الان با `curl` از همین ماشین freebuff.com و artificialanalysis.ai و requesty.ai و gapgpt.app/gapcode و github.com را خواندم. و `webfetch` روی URL مستقیم جواب می‌دهد.
- پس **Devin لازم نیست.** فرمول بهتر: شما فقط **لینک** بدهید (مثل همین freebuff و Jev که دادید)، من می‌خوانم و تحلیل می‌کنم. اگر Devin چیزی پیدا کرد، لینک یا متن خامش را بدهید تا وارد تحلیل کنم.
- نکته: DuckDuckGo یک‌بار جواب داد بعد rate-limit شد (همان‌جا مدرک Cursor را گرفتم — بخش ۱).

### ۰.۳ لحن اعداد شهودی — اصلاح شد (پاسخ به هر دو «نظر»)
- جمله ناشیانه قبلی حذف. فرمول جدید (کوتاه، حرفه‌ای، عیناً برای اسلاید):
> «برآورد شخصی سخنران.»
- همین. پنج کلمه زیر هر اسلاید عدد. نه دفاع، نه حمله به پژوهش‌ها، نه توضیح اضافه. نظر دوم شما هم اعمال شد: **دیگر نمی‌نویسم «پژوهش‌ها چه می‌گویند». فقط پیش‌بینی شما می‌آید + همان پنج کلمه.**

## ۲. کاتالوگ عمیق ابزارها (۱۲ ردیف — قلب ارائه)

فرمت هر ابزار در اسلایدها یکدست باشد: **چیست؟ مال کی؟ چه مدل‌هایی؟ قفل یا باز؟ اشتراک یا PAYG؟ به چه دردی می‌خورد؟ یک خط «حرف سخنران».**

### ۲.۱ Hermes Agent — ویترین ارائه (عمومی، باز، چندمدله)
- مال Nous Research، اوپن‌سورس MIT. CLI/TUI + اپ دسکتاپ + Gateway (تلگرام، دیسکورد، واتس‌اپ، سیگنال و ۲۰+ پلتفرم) + cron.
- هر مدلی: Nous Portal، OpenRouter، OpenAI، اندپوینت شخصی (`hermes model`).
- ۶۰+ ابزار داخلی + هر MCP بیرونی؛ ۷ بک‌اند اجرا (local، Docker، SSH، Daytona، Modal...) — روی VPS ارزان هم می‌نشیند.
- تمایز: **حلقه یادگیری** (مهارت می‌سازد، حافظه ماندگار، جست‌وجوی مکالمات قدیمی).
- مدل پول: رایگان (خودت مدل را می‌آوری) + هزینه مدل. **نظر**: خودش هم اشتراک می‌فروشد
- حرف سخنران: «آینده‌ای که می‌گویم را امروز می‌شود لمس کرد.»

### ۲.۲ Claude Code — استاندارد صنعتی کدنویسی ترمینالی (قفل)
- مال Anthropic. فقط مدل‌های **Claude** (قفل اول‌شخص).
- ترمینال‌محور، عمیق در خواندن/ویرایش پروژه و اجرای تست. انتخاب پیش‌فرض خیلی از تیم‌های حرفه‌ای.
- مدل پول: اشتراک (Claude Pro/Max) یا API؛ سهمیه/rate limit دارد.
- حرف سخنران: «اگر فقط یک ابزار حرفه‌ای را عمیق یاد بگیری، همین است.»

### ۲.۳ OpenAI Codex — نماینده اکوسیستم GPT (قفل)
- مال OpenAI. فقط مدل‌های **GPT** (قفل اول‌شخص). نسخه CLI + ابری (روی GitHub).
- از ایده تا PR: مسئله بده، کد + تست + Pull Request بگیر.
- مدل پول: اشتراک ChatGPT Plus/Pro یا API.
- حرف سخنران: «دنیای GPT را از داخل خانه‌اش ببین.»

### ۲.۴ Cursor — IDE ایجنتی، حالا زیر پرچم SpaceXAI (نیمه‌قفل، نکته Grok)
- مال Anysphere؛ **آگوست ۲۰۲۶ با ۶۰ میلیارد دلار به SpaceXAI (xAI سابق) پیوست** — بخش ۱.
- فورک VS Code با Tab ایجنتی، چت روی کل ریپو، عامل چندفایلی. دسترسی ممتاز به **Grok** (نکته شما: به‌گفته سخنران، برای کارهای لحن/روان‌شناختی/افکار عمومی به‌خاطر داده X جالب است — با برچسب «برآورد شخصی»).
- مدل پول: اشتراک ماهانه (سهمیه‌ای) + پلن‌های حجمی. FreeBuff خودش را با Cursor ‎$720/yr مقایسه می‌کند.
- حرف سخنران: «جایی که ویرایشگر و مدلِ هم‌خانواده به هم رسیدند.»

### ۲.۵ GitHub Copilot — همراه همه‌جا (وابسته به GitHub، چندمدله‌شونده)
- مال GitHub/Microsoft. از تکمیل‌خط به **عامل** رسید: Copilot app (از issue تا merge)، CLI، ادغام با Actions و Code Review.
- مدل‌ها: historically OpenAI، امروز انتخاب چندمدله در پلن‌ها (روز ساخت چک شود).
- مدل پول: اشتراک Pro/Business — ارزان‌ترین راه شروع برای دانشجو.
- حرف سخنران: «کم‌اصطکاک‌ترین شروع برای کسی که GitHub دارد.»
**نظر**: توی پلن دانشجویی از پارسال دیگه امکان انتخاب مدل رو نمیده و فقط حالت auto کار می‌کنه. قبلا از همه بصرفه‌تر بود ولی الان نه.
### ۲.۶ Devin — سقف ادعای خودگردانی (ابری، اشتراک گران)
- مال Cognition. عامل ابری که روی تسک‌های بلند (مهاجرت، باگ‌های چندساعته) ادعا دارد.
- ادعای شما (SWE2/Kimi K3/فرانت‌اند) در اسلاید با برچسب «به‌گفته سخنران» می‌آید تا لینک بدهید — بخش ۱.
- مدل پول: اشتراک تیمی گران (FreeBuff مقیاس می‌دهد: ~$2,400/yr). نقطه نقد: هزینه + نیاز به نظارت.
- حرف سخنران: «خودگردان‌ترین، گران‌ترین، و نیازمند بیشترین نظارت.»

### ۲.۷ OpenCode — گزینه هکرها (باز، چندمدله، ارزان)
- اوپن‌سورس، ترمینال، چندمدله (هر پروایدر OpenAI-compatible). قابل self-host.
- مدل پول: رایگان + هزینه مدل خودت (FreeBuff مقیاس: ~$120/yr معادل).
- حرف سخنران: «اگر تحریم/هزینه اذیت می‌کند، این راه فرار است.»
**نظر**: یک چیز به نام open code go دارد که یک جور اشتراک است و ارزان است. خصوصا اگر از مدل muse spark 1.3 contributor استفاده کنید.
### ۲.۸ Z Code — نماینده چین (روی GLM)
- مال Zhipu (برند Z AI)، روی خانواده **GLM** (۵.۳ و نسل بعد). عامل کدنویسی/IDE.
- چرا در ارائه: دنیا فقط آمریکا نیست؛ مسیرهای ارزان/جایگزین برای ایران.
- احتیاط: جزئیاتش تند عوض می‌شود — ۱ اسلاید + تاریخ.
- حرف سخنران: «نیمی از آینده در شرق نوشته می‌شود.»

### ۲.۹ Antigravity — نماینده گوگل (IDE ایجنتی)
- مال Google. محیط ایجنتی (مرورگر/ادیتور عامل‌محور) روی مدل‌های **Gemini**.
- از این IP صفحه‌اش 403 داد ولی وجود و هویتش قطعی است؛ جزئیات روز ساخت چک شود.
- حرف سخنران: «گوگل می‌خواهد خودِ محیطت عامل باشد، نه افزونه‌ات.»

### ۲.۱۰ Mimo Code — نماینده موج مدل‌های چین (MiMo شیائومی)
- خانواده **MiMo شیائومی** در Artificial Analysis و FreeBuff هست (MiMo-V2.6-Flash/Pro). «Mimo Code» نسخه کدنویسی همین خانواده است.
- جزئیات محصول روز ساخت چک شود؛ نقشش در ارائه: «مدل خوب ارزان برای حجم بالا».
- حرف سخنران: «برای کارهای پرحجم، هوش متوسط ارزان بهتر از هوش عالی گران است.»

### ۲.۱۱ GapCode — نماینده ایران (فارسی، دسکتاپ+CLI، چندمدله)
- مال **GapGPT** (درگاه ایرانی، آلترناتیو OpenRouter). مستقیم خواندم: فارسی، دسکتاپ + CLI، کار با فایل/مرورگر/کد، **شروع با اعتبار رایگان**، انتخاب مدل متنوع، نصب روی macOS/Linux/Windows (native + WSL).
- چرا مهم: تحریم و پرداخت. مخاطب ایرانی باید «راه بومی» را بشناسد.
- حرف سخنران: «اگر API خارجی نداشتی، از اینجا شروع کن.»
**نظر**: توجه کن که اکثر مدل‌هایش را فقط پروکسی می‌کند و تنها یک یا دو مدل self host دارد که آن‌ها هم توسط چینی‌ها توسعه داده شده اند و open weight هستند. راستی! به قضیه مدل‌های open weight هم اشاره کن
### ۲.۱۲ FreeBuff — برگ برنده دانشجو (رایگان، چندمدله، همه‌فرم)
- Desktop + CLI + Web + Cloud + Chat. بدون API key و کارت. تبلیغ‌محور.
- منوی روزانه‌اش (بخش ۰.۱) را در اسلاید بگذار: دانشجو با $0 می‌تواند GPT-6 Luna و MiMo و DeepSeek و GLM را لمس کند.
- قید صداقت: «رایگان یعنی محدودیت سهمیه + وابستگی به کشور/VPN + تبلیغ» — همین یک خط اعتبار ارائه است.
- حرف سخنران: «بهانه «پول ندارم» تمام شد.»

## ۳. مدل‌ها — عمیق ولی فشرده (هر مدل ۳ خط در اسلاید)

- **Grok (SpaceXAI):** خانواده LLM + تصویر/ویدیو؛ امتیازش داده X و compute عظیم (Colossus). نکته شما (روان‌شناسی/لحن) با برچسب «برآورد شخصی سخنران».
- **Claude (Anthropic):** استاندارد کدنویسی/استدلال تمیز؛ مرجع در بنچمارک‌ها (Opus 5.5 صدر AA در خبر ۲۲ سپتامبر).
- **GPT (OpenAI) تا خانواده GPT-6 (Sol/Luna/Astra):** مرز قیمت/هوش؛ Sol/Luna در AA «مرز کارایی هزینه» را جابه‌جا کردند. Astra را «نامزد کلاس AGI» معرفی کن ولی **بدون ادعای قطعی** — بخش ۱.
- **Gemini (Google):** زمینه طولانی و چندرسانه‌ای؛ خانه‌اش Antigravity.
- **Kimi (Moonshot):** زمینه طولانی و قیمت رقابتی؛ ادعای SWE2/Kimi K3 شما تا لینک، «به‌گفته سخنران».
- **GLM (Zhipu) و DeepSeek و MiMo (Xiaomi) و Muse Spark:** ستون «ارزان‌های پرحجم» — برای اتوماسیون و map-reduce.
- **Jev (System One):** تنها مدل غیرمتنی کاتالوگ — Choice/Score/Noul، موازی، ۷۰–۵۰۰ms. نقش: تصمیم سریع داخل کد، نه گفتگو. (جزئیات در تحلیل ۰۳.)

## ۴. دو ماتریسی که شما خواستید (عیناً دو اسلاید)

|---|---|
| Claude Code → فقط Claude | Hermes، OpenCode، Cursor (چندمدله ولی Grok‌محور)، FreeBuff، GapCode |

| Antigravity → Gemini‌محور | |
**جمله اسلاید:** «ابزار قفل = عمق در خانه خودش؛ ابزار باز = آزادی انتخاب و فرار از تحریم/قیمت.»

### ۴.۲ اشتراک vs پرداخت به‌مصرف (PAYG)
- **اشتراک (Subscription):** معمولاً ارزان‌تر برای مصرف ثابت، ولی **سقف نرخ (rate limit) و سهمیه** دارد (ساعت شلوغی کند می‌شود). مثال: Copilot، Cursor، Claude، Codex، Devin.
- **PAYG (توکنی/API):** هرچه مصرف کنی همان‌قدر؛ بدون سقف اشتراکی ولی صورت‌حساب غافلگیرکننده. مثال: OpenRouter، Requesty، GapGPT، API مستقیم.
- **راه سوم (ایرانی/رایگان):** اعتبار رایگان GapCode + Freebucks روزانه FreeBuff برای شروع $0.
**جمله اسلاید:** «دانشجو با رایگان شروع می‌کند، حرفه‌ای با اشتراک، شرکت با PAYG و سقف.»
**نظر**: نه شرکت هم از PAYG استفاده نمی‌کنه. بلکه اگر یک نرم‌افزار باشه که خودش از هوش مصنوعی استفاده می‌کنه و مثلا داخلش نرم‌افزار تولید میشه (مثل lovable که خوبه به این دسته هم اشاره بکنی) از PAYG استفاده میشه.

## ۶. کجا بفهمیم کدام مدل بهتر است؟ (دو سایتی که خواستید)

- **Artificial Analysis (artificialanalysis.ai)** — مستقیم خواندم: شاخص **Intelligence Index** (هرچه بالاتر بهتر)، سرعت (توکن/ثانیه)، هزینه هر تسک. مدل‌یاب و بنچمارک سفارشی هم دارد. در اسلاید: اسکرین‌شات روز + این سه ستون + خبرهای ۲۲–۲۷ سپتامبر (Claude Opus 5.5 صدر، GPT-6 Sol/Luna مرز هزینه).

- روش خواندن بنچمارک (۱ اسلاید): هر بنچمارک فقط «یک توانایی» را می‌سنجد (کدنویسی/دانش/عاملیت) + سه تله (آلودگی داده، مهندسی هارنس، خوداظهاری سازنده مثل Jev).
