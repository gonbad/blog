# Idea input — مسئول ثبت‌نام رویداد (مهتاب، Rehearsal #1، اجاره‌ای)

این سند ورودی `/idea-core` برای `01-event-organizer` است؛ در `docs/versions/0.1/00-idea-input.md` قرار می‌گیرد.

## نقش
مسئول ثبت‌نام و هماهنگی رویداد و کارگاه (اجاره‌ای — `is_rented=True`).

## کار روزانه
معرفی رویداد، پاسخ به سؤال‌ها (سرفصل، پیش‌نیاز، تاریخ، ظرفیت)، چانه‌زنی در باند تخفیف، دریافت هزینه ثبت‌نام، ثبت مشخصات (نام، موبایل، لپ‌تاپ)، صدور رسید، اطلاع به برگزارکننده در کانال اعلان.

## رابط کاربر انتهایی
ربات بله (`bale_bot`) + `/work/mcp` (دستیارهای شخصی) + دریافت هزینه با `bale_wallet` و `card_ocr`.

## مدیریت (`/employer/mcp`)
پرسونا و آواتار، عنوان و سرفصل‌ها، ظرفیت، قیمت بلیت، باند تخفیف، توکن ربات، کانال اعلان، ابزار `@employer_tool` (`export_registrants`) و `@work_tool` (`register_attendee`).

## صورت‌حساب عمده (`/broker/mcp`)
به‌ازای هر ثبت‌نام قطعی پرداخت‌شده، کسر از اعتبار بروکر.

## نخستین کارفرما (`self`)
ثبت‌نام واقعی شرکت‌کنندگان کارگاه V6.0 خودِ امید.
