# V0.1 visual and interaction direction

Use the journal's existing Persian Estedad fonts, warm paper, pine ink and rust accent. The opening's terminal illustration is native HTML/CSS. A dark prompt section distinguishes the actionable output; the provider images are actual browser captures. No new stock illustration or generated brand asset is needed.

These visual choices and the working headline are delegated project-local defaults, not requirements for later posts. The owner's explicit root, prompt-first and page-order corrections remain separate confirmed instructions.

Ten manual vertical sections, bottom segments and a reading-mode toggle. Up/Down after buttons/links still navigates; inputs/selects/textareas retain native editing keys, and Space activates a focused button. Reduced motion removes animated seeking. Long phone sections scroll naturally instead of clipping the form into a fixed-height slide.

OS selects available terminals; required non-secret fields gate generation. Every edit invalidates previously generated text, clone/reconnect commands and their copy/download controls. Refresh/reset clears configuration; no storage, database, analytics or runtime requests are used. Explicitly downloaded text is a user-requested local artifact.

Browser review covers desktop, laptop, 390px and 320px widths, the actual downloaded offline archive, local fonts and keyboard/copy behavior. Source is projects/002-claude-server/site/; checks and screenshots are recorded with the release.
