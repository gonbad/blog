# V0.2 style and interaction

Preserve V0.1’s Estedad typography, paper/pine/rust palette, manual vertical navigation and reading mode. Move the existing terminal illustration to the solution; the first scene is the account-closure problem only.

Use separate server and repository forms, masked password/token inputs, a short faded English prompt preview and a native complete-view dialog. Dialog Escape/close restores focus; modal keys must not change the underlying slide. Copy/download operate on the complete artifact, not the preview. Changes to setup data invalidate the previous generated result. Session-name and local-Git controls update independently.

Long phone sections scroll naturally. Inputs and text areas retain native keys; focused buttons still allow presentation Up/Down outside a modal. The old handoff/clone/project-rule visual scenes are removed. All runtime assets remain local for the offline bundle.
