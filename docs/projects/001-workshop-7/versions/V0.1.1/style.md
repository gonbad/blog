# Existing visual and interaction direction

Carry forward the owner's accepted presentation appearance: Estedad, warm paper, dark green ink, red-orange emphasis, independent illustrative scenes, and local assets. Keep phone layouts readable through normal vertical scrolling rather than shrinking a desktop canvas.

Interactions include horizontal example tabs, a clearly local decision demonstration, copyable worksheet text, manual vertical navigation, and a reading mode. Up/Down must navigate after clicks on ordinary controls. Space still activates the focused button; text editing and a widget's own handled keys retain their meaning. No automatic progression, narration or timed segment fill is introduced.
