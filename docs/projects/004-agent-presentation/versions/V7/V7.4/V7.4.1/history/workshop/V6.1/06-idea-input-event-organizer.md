# ورودی ایده — تمرین ۱: مسئول ثبت‌نام رویداد (in-house)

یک کارمند درونی برای خودِ برگزارکننده — نه سکویی که هر برگزارکننده‌ای اجاره کند. صاحبِ کارمند: یک آدمِ واقعی با رویدادهای خودش.

- **کار روزانه:** در بله به سؤال‌های شرکت‌جوها دربارهٔ رویداد جواب می‌دهد، ثبت‌نام می‌کند، پول بلیت را می‌گیرد، فهرست را نگه می‌دارد.
- **رابط کاربر انتهایی:** یک ربات بله (bot) — دکمه، کارت، فُرم.
- **پول:** ثبت‌نام پولی است؛ پیش‌فرض کارت‌به‌کارت با بررسی رسید توسط صاحب کارمند؛ اگر توکن درگاه بله بود، فاکتورِ کیف‌پولی.
- **تصمیم‌های صاحب کارمند در /sops:** ثبت‌نام (پیشنهاد: `direct`) · لغو ثبت‌نام (پیشنهاد: `user_confirm`) · تخفیف بالای کف چانه (پیشنهاد: `owner_confirm`) · ارسال پیامِ انبوه/اطلاع‌رسانی (پیشنهاد: `owner_confirm`).
- **پاکت‌ها:** شمارهٔ موبایل → پاکت ورودیِ contact (تأییدشده) · شمارهٔ کارتِ مشتری در متن → الگو پیش‌فرض · لینکِ خصوصی رویداد → پاکت خروجی.
- **هرگز:** قیمت را خودش عوض نکند؛ به کسی که ثبت‌نام نکرده پیام تبلیغاتی نفرستد؛ پول نزد او نماند (کارتِ صاحب کارمند است).
- **هزینهٔ روزانه:** سقف توکن هر مشتری و کلِ کارمند روشن است؛ بدون مدل هم منو کار می‌کند.
