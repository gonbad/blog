# 007-islamic-astronomy roadmap

These ideas and companion topics are banked for future iterations:

- **Constellations and Star Navigation (صورت‌های فلکی و مکان‌یابی با ستارگان):** Celestial sphere, ecliptic (دایرة البروج), precession (حرکت تقدیمی), and polar star navigation from channel notes.
- **Astrological Concept Clarification (قمر در عقرب):** Astronomical explanation of the Moon passing through the Scorpius constellation and the difference between constellation and astrological sign.
- **Audio-guided narration:** Playable audio walking through each interactive widget step by step.
- **Compass sensor integration:** Mobile web compass API integration for live physical alignment alongside the solar Qibla hour calculation.
