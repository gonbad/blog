# ایجنت — از خواستن تا انجام‌شدن

ارائهٔ جامع ۱۶۷ صفحه‌ای کارگاه همراه با ۲۵ نقشهٔ مسیر و شبیه‌سازهای تعاملی (گفت‌وگوی سفر، شبکهٔ عصبی، محاسبه‌گر هزینه، کنترل‌های دسترسی).

منتشر شده در قالب پست ۰۰۴ یادداشت‌های کارگاه.
مسیر منبع: `site/index.html`.
کاملاً آفلاین و قابل اجرا با پروتکل `file://` بدون نیاز به اینترنت یا سرور محلی.
