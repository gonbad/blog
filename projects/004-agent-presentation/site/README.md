# ایجنت — از خواستن تا انجام‌شدن

`index.html` را مستقیم در مرورگر باز کنید. سرور، نصب و اتصال اینترنت برای اجرای ارائه لازم نیست. برای جابه‌جایی، تمام این پوشه را با هم منتقل کنید.

ارائه ۱۶۷ صفحهٔ محتوایی و ۲۵ نقشهٔ مسیر دارد. پنج بخش: «از خواستن تا انجام‌شدن»، «مدل»، «هارنس»، «ایجنت تولیدکننده محصول» و «زندگی با ایجنت‌ها». تمام صفحه‌ها از زمینهٔ روشن استفاده می‌کنند.

| کلید           | کار                            |
| -------------- | ------------------------------ |
| `←` یا `Space` | گام بعدیِ نمایش؛ سپس صفحهٔ بعد |
| `→`            | صفحهٔ قبل                      |
| `PageDown`     | رفتن مستقیم به صفحهٔ بعد       |
| `G`            | نمای کلی، جستجو و انتخاب صفحه  |
| `N`            | یادداشت سخنران و منابع         |
| `F`            | تمام‌صفحه                      |
| `B`            | توقف تصویر                     |
| `H`            | پنهان/نمایان‌کردن کنترل‌ها     |
| `Home` / `End` | آغاز / پایان                   |
| `?`            | راهنما                         |

شمارهٔ داخل نشانی مثل `#slide-83` شناسهٔ داخلی صفحه را نشان می‌دهد. شمارهٔ پایین صفحه، شمارندهٔ پیوستهٔ صفحات محتوایی است. برای خواندن نمودارها در اندازهٔ بزرگ، روی تصویر بزنید.

برای رفتن به یک صفحه با شمارهٔ نمایشی، `G` را بزنید و شماره را بنویسید؛ مثلاً `۱۸` نمایشِ عددیِ ورودی و خروجیِ مدلِ زبانی را باز می‌کند. ترتیب و شماره‌ها در بازبینیِ ساختاری تغییر کرده‌اند.

نمونه‌های سفر، حلقه، تأیید، شمارهٔ همراه و قطعی مدل، نمایش آموزشیِ محلی‌اند و به سامانهٔ واقعی درخواست نمی‌فرستند. نمودارها و جزئیات طرح‌ها مربوط به ۴ نوامبر ۲۰۲۶ هستند.

منابع و اعتبار تصاویر در [sources.html](sources.html) ثبت شده‌اند. نسخه‌های پیشین ارائه در تاریخچهٔ گیت نگهداری می‌شوند؛ پروندهٔ مستندات پروژه، متن کامل تصمیم‌ها و بازخوردها را حفظ می‌کند.

در گفت‌وگوی سفر، هنگام نمایش گزینه‌ها یکی را انتخاب کنید و برای رزرو، دکمهٔ تأیید داخل گفت‌وگو را بزنید. فایل‌های نمونهٔ بلیت و واچر هتل واقعاً دریافت می‌شوند و اعتبار سفر ندارند.

در مثال شبکه، «یک گام آموزش» و «۲۰ گام آموزش» وزن‌ها را با نمونه‌های برچسب‌دار تغییر می‌دهند. در صفحهٔ بعد، تغییر دستی وزن از آموزش جداست. مثال دما هم توزیع احتمال و انتخاب را تغییر می‌دهد.

شبکهٔ همین مثال ۱۰۸ وزنِ اتصال و ۶ بایاسِ آموزش‌پذیر دارد؛ در مجموع ۱۱۴ پارامتر. شمارش در صفحهٔ معرفیِ شبکه هم نمایش داده شده است.

نمایش‌های قبلیِ شبکه، دما و گفت‌وگوی سفر حفظ شده‌اند. مجموعهٔ دوازده تصویرِ آموزش و دو تصویرِ خارج از آموزش جدا نمایش داده می‌شوند؛ آزمودنِ تصویرِ تازه، وزن‌های شبکه را تغییر نمی‌دهد. در نمایشِ زبان، ورودی، بردارها، وزن‌های ثابت و احتمالِ ادامه از هم جدا هستند. این محاسبهٔ کوچک، مدلِ زبانیِ واقعی نیست.

برای بازبینی با `G`، شمارهٔ نمایشی را وارد کنید:

| صفحه    | موضوع                                                    |
| ------- | -------------------------------------------------------- |
| ۲۹–۳۳   | دیتاستِ ارزیابی، بنچمارک‌ها و نمودارهای واقعی            |
| ۳۸–۴۶   | مدل‌های به‌روز، Contributor، اجرای محلی و نرخِ ساعتِ اوج |
| ۴۷–۴۸   | انتخاب برای ساخت/اجرا و نردبان اعتماد                    |
| ۴۹–۵۴   | اشتراک، مصرف و هزینه                                     |
| ۵۵–۶۷   | هارنس، ابزار، سرویس‌های جستجو و RAG                      |
| ۶۸–۷۱   | ساختِ زمینه و پیدا کردنِ سابقهٔ لازم                     |
| ۷۲      | حلقهٔ چندمرحله‌ایِ سفر و تأییدِ مستقل                    |
| ۷۴–۱۰۸  | اداره، اختیار، حساب، داده، اتصال و قطعی                  |
| ۱۰۹–۱۳۵ | ایجنت تولیدکننده محصول، روشِ مرحله‌ای و کدو              |
| ۱۳۶–۱۴۰ | دستیارِ شخصی، ایجنتِ آژانس و MCP                         |
| ۱۴۱–۱۵۶ | سیستم‌عامل، اجرای محلی و تجربه‌های داستانی               |
| ۱۵۷–۱۶۷ | آیندهٔ کار؛ نساجی، مُهر، تغییرِ سیاسی و سرمربی           |

در نمایش‌های مرحله‌ای، `Space` یا «گام بعد» را بزنید. حلقهٔ صفحهٔ ۷۲ دوازده گام دارد؛ در گامِ تأیید، فقط دکمهٔ مستقلِ سارا ادامهٔ رزرو را مجاز می‌کند. «از ابتدا» وضعیتِ همان نمایش را پاک می‌کند. کلید `PageDown` مستقیماً به صفحهٔ بعد می‌رود.

در صفحهٔ ۶۵، دو لغزنده مختصات، زاویه و رتبه‌بندیِ بردارها را تغییر می‌دهند. در صفحهٔ ۵۰، تعداد نوبت‌ها و فرضِ Cache Hit را عوض کنید. در ۶۸ اجزای ورودیِ مدل را انتخاب کنید؛ در ۷۱، سابقهٔ موجود، سابقهٔ بازیابی‌شده و نتیجهٔ مبهم را مقایسه کنید. در ۱۱۲، خروجیِ ترجمه، پژوهش، سایت و ایجنت را بررسی و اصلاح کنید. صفحهٔ ۱۳۹ تعدادِ پیاده‌سازی‌های اتصال با و بدون قراردادِ مشترک را مقایسه می‌کند.

محیط‌های Claude Code، Cursor، Codex، OpenCode و Antigravity در صفحهٔ ۱۱۸ به‌صورت نمای آموزشی معرفی شده‌اند؛ تصویرِ واقعیِ رابطِ این سرویس‌ها نیستند. صفحاتِ هزینه، طرح‌های دسترسی را معرفی می‌کنند؛ این صفحه نقش ایجنت‌های تخصصی کدنویسی را توضیح می‌دهد. هر یک از پنج محصول «سایت، ایجنت، پژوهش، ترجمه، تألیف» را انتخاب کنید تا فایل‌ها و معیار بررسی آن تغییر کند. در صفحهٔ ۱۱۶ سه روش تولید محصول مقایسه می‌شوند و صفحهٔ ۱۱۷ در چهار گام، نمونهٔ کمک در خرید و تبدیل تجربه به مهارت و کدِ قابل استفادهٔ دوباره را نشان می‌دهد. منبع رسمی مهارت‌های هرمس در ۵ نوامبر ۲۰۲۶ بررسی شده است.

نمایش‌ها آموزشی و محلی‌اند. محاسبهٔ هزینهٔ گفتگو با نرخِ فرضی انجام می‌شود؛ نرخ‌های Meta و DeepSeek مثال‌های تاریخ‌دار از مستنداتِ رسمی‌اند. نمایشِ بازیابی، تولید متن و جستجو، مدل یا سرویسِ زنده را صدا نمی‌زند. امتیازِ سه بررسیِ نمونه، نمرهٔ یک مدلِ واقعی نیست. کنترل‌های مجوز و داده، رفتارِ یک نمونهٔ کوچک را نشان می‌دهند. روایتِ آیندهٔ کار و تغییرِ قواعد، سناریوی ارائه است و نمودارِ مُهر، قیمتِ واقعی ندارد.
