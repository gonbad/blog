۰۲ / راهکار

در اسلایدهای بعد، قدم‌به‌قدم این محیط را آماده می‌کنی.

۰۳ / خرید سرور

یک سرور با
این مشخصات بخر.

۴ GBرم یا بیشتر۲ vCPUیا بیشتر۲۰ GBدیسک یا بیشترUbuntu24.04

می‌توانی از وی‌پی‌اس مارکت بخری:

https://vpsmarket.org/vps-canada/

یا از هر فروشندهٔ دیگری که ترجیح می‌دهی؛ سرور باید خارج از ایران باشد و این مشخصات را داشته باشد.

در تصویر، پلن CA 4 کانادا ۴ گیگ رم، ۲ هسته و ۳۰ گیگ SSD دارد. قیمت نمایش‌داده‌شده مربوط به ۹ نوامبر ۲۰۲۶ است؛ مبلغ نهایی را هنگام خرید ببین.

چرا در بین پلن‌های هم‌قیمت، کانادا را انتخاب کردیم؟

پلن‌های مناسب کانادا، آلمان و فرانسه در بررسی ما هم‌قیمت بودند. برای مقایسهٔ مالیات اشتراک کلود، GST فدرال کانادا ۵٪ است و مالیات استان می‌تواند به آن اضافه شود؛ مثلاً انتاریو ۱۳٪ HST دارد. نرخ استاندارد آلمان ۱۹٪ و فرانسه ۲۰٪ است.

کلود مالیات را با آدرس صورتحساب روش پرداخت حساب می‌کند؛ کشور سرور به‌تنهایی مالیات اشتراک فعلی را تغییر نمی‌دهد.

مبنای صورتحساب کلود · نرخ‌های کانادا · نرخ‌های اروپا

وقتی سرور آماده شد، اطلاعات ورودش را از پنل فروشنده بردار و به اسلاید بعد برو.

۰۴ / اطلاعات سروری که خریدی

اطلاعات سرورت را
اینجا وارد کن.

آی‌پی، نام کاربری، رمز و درگاه SSH را از پنل فروشنده بردار. معمولاً نام کاربری root و درگاه 22 است.

این اطلاعات در حافظهٔ همین صفحه می‌مانند و داخل پرامپتی که کپی یا دریافت می‌کنی قرار می‌گیرند.

اطلاعات ورود را کامل کن.

۰۵ / اگر مخزن از قبل هست، همان را استفاده کن

پروژه و توکنش را
در گیت‌هاب آماده کن.

۱ / ساخت پروژه

مخزن را بساز

این صفحه را باز کن:

https://github.com/new

نام مخزن و دسترسی عمومی یا خصوصی را انتخاب کن و Create repository را بزن. برای یک مخزن کاملاً تازه می‌توانی README را هم اضافه کنی تا اولین فایل ساخته شود.

در صفحهٔ مخزن، Code → SSH را باز کن و آدرس را برای اسلاید بعد کپی کن. اگر پروژه‌ات از قبل هست، همان آدرس را بردار.

۲ / توکن همین مخزن

توکن با اجازهٔ خواندن و نوشتن بساز

https://github.com/settings/personal-access-tokens/new

برای توکن نام و زمان اعتبار انتخاب کن. در Repository access، گزینهٔ Only select repositories و همین مخزن را انتخاب کن.

در مجوزهای مخزن، Contents را روی Read and write بگذار و Generate token را بزن. توکن ساخته‌شده را برای اسلاید بعد کپی کن.

اگر توکن مناسبی از قبل داری، همان را استفاده کن.

۰۷ / روی کامپیوتر خودت انجام بده

این پرامپت را به
هوش مصنوعی کامپیوترت بده.

  1. یک دستیار دارای دسترسی به ترمینال را روی کامپیوترت باز کن؛ مثلاً Claude Code یا Codex، یا Claude Desktop با ابزار ترمینال متصل.
  2. اجازهٔ اجرای دستورها و دسترسی به فایل‌ها را به آن بده؛ حالت دسترسی کامل ابزار را انتخاب کن.
  3. دکمهٔ کپی پرامپت را بزن و متن را در گفت‌وگوی همان دستیار بفرست. صبر کن تا آماده‌سازی را انجام بدهد.

۰۸ / بعد از تمام‌شدن کار دستیار

ترمینال کامپیوترت را باز کن.
این دستور را اجرا کن.

دستور زیر را کپی و در ترمینال کامپیوتر خودت وارد کن. به سرور و همان نشست کارت وصل می‌شوی؛ اگر نشست نباشد، ساخته می‌شود.

اتصال به نشست work
ابتدا اطلاعات سرور و گیت‌هاب را کامل و پرامپت را بساز.

برای جدا شدن از نشست، Ctrl+B را بزن و رها کن، بعد D را بزن. برای ورود به کلود، دو اسلاید جلوتر را ببین.

۰۹ / نشست قبلی سر جایش می‌ماند

یک نام بده.
به آن نشست وصل شو.

برای یک کار دیگر، نام تازه‌ای وارد کن. دستور را در ترمینال کامپیوترت بزن؛ اگر این نام از قبل وجود داشته باشد، همان نشست ادامه پیدا می‌کند.

ساخت یا ادامهٔ نشست با این نام
ابتدا پرامپت آماده‌سازی را بساز.

۱۰ / اولین ورود روی سرور

در ترمینال سرور،
claude را اجرا کن.

  1. بعد از اتصال به نشست، دستور روبه‌رو را بزن.
  2. در اولین اجرا، کلود ورود به حساب را می‌خواهد. لینک ورود را در مرورگر کامپیوتر خودت باز کن و با حساب اشتراکت وارد شو.
  3. به ترمینال سرور برگرد؛ فقط اگر کلود کد ورود خواست، کد نمایش‌داده‌شده را آنجا وارد کن.

ورود روی سرور ثبت می‌شود و دفعات بعد از همان حساب استفاده می‌کنی.

۱۲ / اگر فایل‌ها را روی کامپیوتر خودت ویرایش می‌کنی

قبل از ویرایش، pull.
بعد از ذخیره، push.

مسیر نسخهٔ محلی همین پروژه را بده و نام شاخهٔ اصلی آن را انتخاب کن. دستور قبل از ویرایش را بزن، فایل‌ها را تغییر بده و ذخیره کن، سپس دستور بعد از ویرایش را اجرا کن.

مسیر پوشه را وارد کن.

قبل از ویرایش

مسیر پوشه و شاخه را مشخص کن.

بعد از ذخیرهٔ فایل‌ها

مسیر پوشه و شاخه را مشخص کن.
